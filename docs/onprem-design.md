### 5.1 문서 인제스트 파이프라인

### 5.2 감사 추적 (레코드 Header, Interceptor)

<!--

Interceptor로 표준 헤더 삽입과 민감정보 삭제 처리를 클라이언트 코드 변경 없이 수행한다.

### 5.7 도입 판단 기준선

| 조건 | 판단 |
|---|---|
| 동시 사용자 수십 명, 단일 서버 | 불필요 |
| 문서 소스가 여러 개이고 갱신이 잦음 | 인제스트 큐로 검토 |
| 로그 소비처 3곳 이상 | 도입 근거 성립 |
| 감사 로그 보존 의무 발생 | 도입 근거 성립 |
| 다중 인스턴스 수평 확장 | 도입 |
